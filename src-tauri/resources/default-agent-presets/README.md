# Default Agent Presets

这个目录用于固化 NineClaw 随应用一起打包的默认智能体预设。

每个 `*.json` 文件描述一个默认智能体，包含两层内容：

- 数据库层：名称、简介、系统提示词、模型、技能、允许工具、协作配置
- 工作区层：`IDENTITY.md` / `ROLE.md` / `MEMORY.md` / `TOOLS.md` 等默认文件内容

设计原则：

- 新安装用户会自动拿到这些预设智能体
- 预设智能体后续仍然可以像普通智能体一样编辑
- 如果用户想恢复出厂配置，可以按 `id` 重置回这里定义的默认值
- 这里优先放“稳定默认值”，不放每天变化的运行记忆或历史日志

后续如需增加新的默认智能体，直接新增一个 `*.json` 文件，并在
`src-tauri/src/agent_presets.rs` 里注册即可。

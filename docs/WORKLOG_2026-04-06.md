# NineClaw 工作记录

日期：2026-04-06

## 今日完成

### 1. Bot 与运行时问题修复

- 修复了微信 `clawbot` 收到消息后触发 `pi 处理超时` 的问题。
- 统一了聊天主链路、bot 链路、heartbeat 链路使用的 `pi runtime` 启动环境，避免部分链路仍然落到错误的 debug runtime。
- 补充了 `pi_path` 等关键日志，方便后续确认实际运行时路径。
- 修复了飞书 bot 启动状态误判问题，不再把 `ws client ready` 当作真实连接成功。
- 为飞书 helper 增加了本地回环代理失败后的直连重试兜底，降低被本机代理拦截导致无法绑定的概率。

### 2. 设置项与技能管理体验优化

- 去掉了设置里的 `IM 机器人设置` 入口，避免无效配置入口继续暴露给用户。
- 优化了智能体编辑中的技能选择弹窗。
- 优化了智能体已挂载技能列表。
- 优化了“探索技能”页中的技能卡片展示。
- 技能说明支持折叠/展开，长描述不再整块撑开界面。
- 技能描述解析修复为支持 `SKILL.md` 中 `description: |`、`description: >` 等多行 YAML 写法，不再只取首行。

### 3. 会话与聊天主界面优化

- 收紧了左侧会话列表的上下留白，提高同屏会话数量。
- 会话标题改为基于对话内容自动提炼短标题，目标长度约 10 到 20 个字。
- 优化了任务执行中的加载态：
  - 去掉首包等待阶段外层大框。
  - 改为更轻的动态等待指示。
  - 执行耗时只保留一处显示。
- 优化了工具调用卡片：
  - 默认更紧凑。
  - 工具名和展开入口放在同一行。
  - 字号统一。
  - 内容默认不抢主信息区。
- 用户提问气泡字体做了收轻处理，避免过粗过大。
- 用户提问区域增加了复制功能。

### 4. 对话附件与输入框附件改造

- 修复了对话区图片、视频、本地文件附件的预览链路。
- 新增本地媒体预览读取命令，前端不再完全依赖不稳定的本地路径转换。
- 对话区图片可正常预览、点击放大。
- 对话区视频可正常内嵌播放。
- 对话区文件附件点击后走系统默认应用打开。
- 输入框中的图片附件改为显示真实缩略图，不再只显示“图片”字样。
- 新发出的附件改为写入结构化 `::nc-media` 标记，减少后续解析歧义。
- 对话区附件样式做了多轮收敛：
  - 去掉附件外层多余边框。
  - 图片不再显示冗余路径信息。
  - 图片只保留单个标题名。
  - 图片尺寸上限进一步压小，避免在对话区中过大。
  - 文件附件保持单层紧凑样式。

### 5. 其他界面细节优化

- 任务输入区与对话区的附件展示职责重新分离，避免错误修改到输入框原样式。
- 对话区文件卡片样式重新调整为更接近输入框附件条的紧凑表达。
- 多处技能卡片、资源卡片、弹窗布局和响应式细节做了收口。
